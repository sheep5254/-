# 开机自启动设置（可视化）

桌面上有个图标 **「开机自启动设置」**（`~/桌面/开机自启动设置.desktop`），双击打开。

## 能做什么

| 功能 | 说明 |
|---|---|
| **选择自启动哪个程序** | awake1.0 自瞄 / TJ2.1 自瞄 / 自定义命令 |
| **一键开关** | 「启用并保存」/「停用自启动」，改完立刻生效，不需重启 |
| **选择启动时机** | ① 登录桌面后启动（推荐，最稳，不要密码）<br>② 开机即启动、不用登录（systemd 用户服务 + linger） |
| **启动延迟** | 默认 8 秒，等 USB 相机/串口枚举完成（TJ2 用的是 5~8 秒） |
| **立即启动 / 停止** | 不等重启，当场测试配置对不对 |
| **查看日志** | 直接看运行日志的最后 400 行 |

## 为什么不用 TJ2 那种 systemd 系统服务

TJ2.0/TJ2.1 用的 `/etc/systemd/system/*.service` 属于**系统级**服务，写它需要 **sudo**。
本工具改成**用户级**：

- `~/.config/autostart/awake-autostart.desktop` —— 登录桌面后启动（XDG 标准）
- 或 `~/.config/systemd/user/awake-autostart.service` + `loginctl enable-linger` —— 开机即启动

两者都不需要密码，效果一样。

## 生成的文件

| 路径 | 作用 |
|---|---|
| `~/.config/awake-autostart/config.json` | 你的选择（目标程序 / 模式 / 延迟） |
| `~/.config/awake-autostart/start.sh` | 启动包装脚本（自动生成，别手改） |
| `~/.config/awake-autostart/logs/start-<日期>.log` | 运行日志 |
| `~/.config/awake-autostart/run.lock` | flock 锁，防止启动两个实例 |
| `~/.config/autostart/awake-autostart.desktop` | 桌面登录自启动入口 |
| `~/.config/systemd/user/awake-autostart.service` | systemd 模式的自启动入口 |

包装脚本做四件事（照抄 TJ2.0/TJ2.1 的 `autostart.sh` 思路）：

```bash
flock -n 9 || exit 0     # 相机和串口都是独占设备，绝不允许跑两个
sleep 8                  # 等 USB 设备就绪
cd <工作目录>            # 注意：必须切目录，否则相对路径的配置找不到
setsid <命令> >>日志 2>&1 &   # 独立进程组，方便一键整树停止
```

## 命令行也能用（脚本/远程场景）

```bash
cd ~/下载/awake1.0
python3 tools/autostart_gui.py status                # 看状态
python3 tools/autostart_gui.py enable awake1.0       # 启用 awake1.0
python3 tools/autostart_gui.py enable tj2.1          # 换成 TJ2.1
python3 tools/autostart_gui.py enable awake1.0 systemd   # 开机即启动模式
python3 tools/autostart_gui.py disable               # 停用
python3 tools/autostart_gui.py start                 # 立刻启动一次（测试）
python3 tools/autostart_gui.py stop                  # 停止
python3 tools/autostart_gui.py log                   # 看日志
```

## ⚠️ 注意

1. **awake1.0 和 TJ2.1 不能同时自启动** —— 它们抢同一个迈德威视相机（`f622:1041`）和同一个串口。
   本工具的 flock 只会拦住「同一个包装脚本」的重复启动；如果两个项目各自从自己的
   systemd 服务启动，锁是分开的，照样会抢。所以：**把 TJ2.1 的系统服务关掉**
   （`sudo systemctl disable tj2-autoaim.service`），统一由本工具管理。
2. TJ2.1 的 `autostart.sh` 里有个 `TJ2_AUTOSTART_DISABLED` 守卫，已改成
   `TJ2_AUTOSTART_DISABLED=${TJ2_AUTOSTART_DISABLED:-1}`：不设环境变量时仍然**默认禁用**
   （保持原来的安全行为），本工具选择 TJ2.1 时会传 `=0` 让它真正启动。
3. 「停止」只杀**本工具启动的**进程（按 pid 文件 + `/proc` 精确匹配进程组），
   并且会拒绝任何与当前会话同组的进程，不会误杀别的程序。
